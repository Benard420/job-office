# Job Office

A personal job search office inside Claude, for anyone, in any country and any field.

Say **"set up my job office"** in a new project and Claude welcomes you, explains what it can and cannot do, and asks for your CV. From there it finds roles that fit, writes tailored cover letters, fills in and submits applications in your own browser, drafts outreach, tracks every application in a spreadsheet and dashboard, coaches you for interviews, and helps you settle into the new role.

## Install

**Claude Code**
```
/plugin marketplace add Benard420/job-office
/plugin install job-office@job-office
```

**Claude app**
1. Download the plugin file: [job-office.plugin](https://github.com/Benard420/job-office/raw/main/dist/job-office.plugin)
2. Open a Claude chat and attach the file (or drop it in).
3. Press the button on the card that appears to add it.
4. Say "set up my job office" in a new project.

## What you need

- Claude in Chrome (the browser extension), signed in to your job sites
- Optional: Gmail or Outlook connected, and scheduled tasks for the daily job scan

See [plugins/job-office/README.md](plugins/job-office/README.md) for the full guide.
